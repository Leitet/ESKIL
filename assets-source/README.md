# Källbilder

Original som INTE ska driftsättas. Allt under `public/` hamnar på webben, så
tunga original hör hemma här i stället — och den webbanpassade versionen läggs
i `public/assets/`.

| Original | Används som | Kommando |
|---|---|---|
| `johan_leitet_scout.png` (2,1 MB, 1122×1402) | `public/assets/johan-leitet.jpg` (114 kB, 600×750) | `sips -Z 750 --setProperty format jpeg --setProperty formatOptions 82 <in> --out <ut>` |

Porträttet visas 200 px brett på Om-sidan. 2,1 MB för den ytan är slöseri med
någons mobildata — särskilt som ESKIL i övrigt är byggt för att fungera på ett
dåligt nät.
